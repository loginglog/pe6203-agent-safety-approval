## Getting started

After access to the current code is arranged, follow the relative-path [installation and local-configuration steps](docs/handoff.md#getting-started-after-code-access-is-arranged). Current inspected environment: Python 3.12.14, AgentDojo 0.1.35 at commit `089ed468cf3ed0322acc66b0211f26d9d90dbf60`, benchmark v1.2.2, OpenAI SDK 3.31.0; full transitive dependencies are not locked.

**OpenAI SDK 3.31.0 is required for all future reproduction.** After creating the Python environment as described in the handoff, install the shared [requirements.txt](requirements.txt) from the repository root and verify the exact version:

```bash
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -c "from importlib.metadata import version; actual = version('openai'); print('OpenAI SDK:', actual); assert actual == '3.31.0', 'Expected openai==3.31.0; install requirements.txt before continuing'"
```

Stop if the version check fails. Do not install an unconstrained OpenAI SDK or use `pip install --upgrade openai`. The requirements pin AgentDojo's source commit and the SDK version; they do not claim a complete transitive dependency lock. The earlier local reproduction with SDK 3.35.1 remains separate historical evidence.

The [October 19 SDK-pinned re-verification](results/teammate_sdk_pin_20261019.json) records 106 rule checks and 35 runner checks passing with SDK 3.31.0 and zero real model API requests. These overlapping check groups are separate offline evidence, not a formal benchmark result or a complete dependency-lock verification.
